# Medicine Expiry & Stock Manager

A responsive web application for managing medicine inventory, stock levels and expiry dates.

## Features
- Dashboard with total, low-stock, expiring-soon and expired counts
- Add, edit and delete medicines
- Automatic expiry status calculation
- Automatic low-stock detection
- Search and filter medicines
- Alerts page
- Responsive design
- Browser localStorage for data persistence
- No backend required

## Run locally
Open `index.html` in a modern browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and open the generated GitHub Pages URL.
